# 🏨 Hotel Booking Cancellation Prediction

A machine learning project that predicts whether a hotel booking will be **cancelled or not** using historical booking data.

## 📌 About the Project

The project focuses on analyzing hotel booking patterns, identifying factors related to cancellations, and building classification models to predict booking cancellations.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🔄 Workflow

```text
Data Collection
      ↓
Data Cleaning & Preprocessing
      ↓
Exploratory Data Analysis
      ↓
Feature Engineering
      ↓
Model Training
      ↓
Model Comparison
      ↓
Final Prediction Model
```

## 🤖 Machine Learning Models

The project compares multiple classification algorithms, including:

* K-Nearest Neighbors
* Naive Bayes
* Logistic Regression
* Decision Tree
* Random Forest
* AdaBoost
* Gradient Boosting

## 🎯 Target Variable

`is_canceled`

* `0` → Not Cancelled
* `1` → Cancelled
